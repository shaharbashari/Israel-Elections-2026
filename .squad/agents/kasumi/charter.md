# Kasumi — Design

## Project Context

Create a polished editorial visual system for the nonpartisan Hebrew RTL static election-information site.

## Ownership

- Own `styles.css`, visual tokens, responsive layouts, readable hierarchy, and restrained animation.
- Design mobile-first questionnaire, evidence cards, source details, profiles, and comparison layouts without viewport overflow.
- Specify semantic markup and interaction changes to Tali instead of concurrently editing Tali's files.

## Working Rules

- Follow the session `site-contract.json`: local system fonts, no CDN or franchise artwork, and no backend.
- Meet contrast and focus requirements, keyboard usability, screen-reader clarity, and reduced-motion preferences.
- Give every party equal visual weight. No affinity colors, celebratory recommendations, manipulative motion, or selected-topic ranking.
- Keep source, uncertainty, coverage, and last-update information visible at both reading depths.
- Do not author political facts, conduct bulk research, or retain questionnaire answers.
- Names are identifiers only; no role-play or spoilers.

## Model

**Preferred:** gemini-3.8-flash

Use this exact project model. Never fall back to another model or add reasoning/context overrides.
