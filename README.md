# בחירות בישראל — שאלון עמדות וכלי קריאה מקומי

פתחו את `index.html` לצד `styles.css`, `app.js`, `data.js` ו־`quiz-data.js`. אין צורך בהתקנה או בשרת. התשובות והחישוב נשארים בדפדפן; קישורי המקורות נפתחים רק לפי בחירה.

## ביקורת המקורות

המחקר עודכן ב־**9 באוקטובר 2026**. המאגר משווה **14 מסגרות פוליטיות**, לא 14 רשימות קלפי עצמאיות ולא את כלל 38 הרשימות שבדיווח על הקצאת האותיות.

- ביחד: **רק**; עוצמה יהודית: **ב**; נעם: **ני**.
- חד״ש, תע״ל ובל״ד מתמודדות ברשימה המשותפת: **ודם**. הפרופילים הנפרדים באתר מתארים מרכיבים של אותו פתק.
- יוסף ג׳בארין החליף את איימן עודה בהובלת חד״ש; יעקב אשר החליף את משה גפני בהובלת דגל התורה. פרישת סאמי אבו שחאדה מרשימת 2026 מוצגת בפרופיל.
- סמוטריץ׳ ופייגלין חתמו על **בלוק טכני**, לא מיזוג מלא; מפלגת סער התמזגה בליכוד ב־2025.

פרטי המקורות והסתייגויות הגישה מופיעים בנתונים ובממשק. תוצאת HTTP מוצלחת אינה אימות כל תוכן המקור, ופרסום מפלגתי מוכיח הצהרה או הבטחה — לא ביצוע. עמוד הבחירות הממשלתי נמצא באינדקס והוצלב עם דיווחים, אך קריאתו המלאה נחסמה; רשימת מועמדים רשמית מלאה לא נבדקה ישירות.

`retrievedAt` הוא חותמת הייחוס המשותפת של ביקורת המקורות, לא שעה מדויקת של כל בקשת HTTP. תאריך פרסום שלא אומת נשמר כ־`null` ומוצג כלא ידוע.

## השאלון ומגבלותיו

נבדקו **32 שאלות ו־448 עמדות**. נשמרו **141 דירוגים עם אסמכתאות**; **307 עמדות ללא תיעוד מתאים** מסומנות `val: null` ואינן נספרות. אין להציג חוסר תיעוד כהימנעות, פשרה או התנגדות.

הסולם ‎-2 עד ‎+2 הוא **פרשנות עריכתית**, לא סולם רשמי או מדד מדעי. יש לבדוק את מספר השאלות המכוסות ליד כל אחוז: הכיסוי משתנה בין המסגרות. כשאין עמדות מתועדות בשאלות שנענו, אין אחוז התאמה. הסיכומים אינם ציטוטים מילוליים.

שאלות הגיור, הבריאות, התחבורה והאקלים הופרדו מהנחות שלא הוכחו. שאלת החטופים עוסקת במקרה עתידי: לפי הדיווח, החטוף האחרון שנותר בעזה הושב ב־26 בינואר 2026. שאלת עונש המוות מציינת שהחוק עבר בקריאות הסופיות במרץ 2026.

## עדכון וולידציה

`data\research.json` הוא המקור היחיד לפרופילים. `quiz-data.js` כולל נימוקים, מזהי מקורות ותאריך ביקורת לכל דירוג. אין להמציא מקורות, ציטוטים, הבטחות או רשומות הצבעה.

הסקריפט `assemble_research.js` מסריאל את **אותו אובייקט** ל־`data.js` בלי לייצר עובדות או לשנות את המחקר. `generate_enriched_data.js` נשמר כפקודה תואמת לפעולה זו בלבד; קובצי `policy_data_part*.js` נגזרים מהמחקר הקנוני ואינם מאגרי עובדות עצמאיים.

```powershell
node .\assemble_research.js
node --check .\quiz-data.js
node --check .\app.js
node --test .\tests\fact-check.test.cjs
node -e 'const { validateResearch } = require("./app.js"); const fs = require("fs"); const d = JSON.parse(fs.readFileSync("data/research.json", "utf8")); console.log("valid:", validateResearch(d).valid);'
```

הבדיקות מאמתות מבנה, הפניות, שוויון הסריאליזציה והתנהגות החישוב; הן אינן מחליפות בדיקת מקורות אנושית.
